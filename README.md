# Pulisci Pupù · Il Negoziatore

Gioco di negoziazione a scene animate: devi piazzare lo spray Pulisci Pupù presso aziende generate a caso.

- `index.html` – build standalone pronta da aprire nel browser.
- `src/head.html` – markup e stili; `src/engine.js` – renderer canvas (personaggi, stanze, camera, fumetti); `src/content.js` – aziende, tratti, portieri, luoghi, obiezioni, imprevisti, leve; `src/game.js` – stato, albero dei dialoghi, trattativa, carriera.
- `./build.sh` – riassembla `index.html` e `dist/pulisci-pupu.html` dai sorgenti.
